Appendix

Everything else gathered on 2026-09-16 while deciding whether an LLM fetch can take enrichment off the VM.

A. Recommendation

Use gpt-5-mini for the verdict, the brand names, Rooster detection and contacts. Keep a raw-HTML fetch for the CTA hrefs. The model is accurate and cheap on everything that lives in the page text, and it does not depend on the VM, the proxy pool or GoLogin. It cannot see anchor URLs on most sites, so tracking links have to come from HTML, which a plain server-side fetch or the VM browser already provides.

  • Wire it into the fetch-error branch of app/api/enrichment/score-row/route.ts first: every row the VM could not read gets one gpt-5-mini call returning all fields at once.
  • Review the 36 disagreements above. They point at a systematic false-positive pattern in the HIGH / VERY_HIGH affiliate heuristic: operators, B2B vendors, game providers and newspapers flagged as affiliates.
  • Settle the billing question on the OpenAI usage dashboard for 2026-09-16: near 0 web-search calls means page opens are free ($0.006 per site); near 700 means each open bills ($0.044 per site).
  • Rename OPENAI_APIKEY to OPENAI_API_KEY in .env.local and add it to Vercel. The existing production fallbacks read the underscore name and are inactive.
  • Prompt hygiene already applied in this run: Cloudflare placeholder reported as obfuscated, full hrefs requested, page opens capped at 3.

What this means. An LLM fetch helps because it runs on OpenAI's infrastructure and never touches the VM, the proxy or GoLogin. It does not help by defeating bot walls: it honours robots.txt, cannot run JavaScript, and in this run 15 of 175 sites blocked it outright. The 33 "error" pages were mostly deleted paid placements or spam pages that no fetcher would rescue.

D. Pricing: who can open a URL, and what it costs

Live prices checked on 2026-09-16. OpenAI exposes page fetching only through its web search tool, whose open_page action needs a reasoning model; every gpt-5 mini and nano qualifies. Anthropic has a dedicated web fetch tool with no per-call fee. Estimates assume a 10 kB page and a short JSON answer.

Measured in this run: gpt-5-mini used ~21k input tokens per site on average and no general searches at all, so the actual token cost was $0.006 per site. Neither is a bot-wall bypass: since 2026-09-15 Cloudflare blocks the "Agent" bot category (ChatGPT-User, Claude-User) by default on new zones.

E. Side finding: Monday-inherited contacts are contaminated

Discovered while picking ground truth. One email, ben.friedman@bitcoin.com, sits on 5,101 rows of contact_table with source = 'monday', every one traced to Monday item 1237399152, across at least 79 unrelated domains (cardplayer.com, casinobeats.com, pokerstrategy.com, gameshub.com). That is 9% of all 57,044 Monday-sourced contact rows. Other repeat offenders: rick@slotozilla.com on 20 domains, deutschland@gmbl.network on 19, contact@lebarbouille.com on 14. Many inherited contact-page URLs are CSS files or random article links.

Likely cause is the brand-stem TLD rematch in the Monday inheritance over-matching. Not fixed. For this report, Monday-sourced contacts were ranked down when choosing samples, and the model's contacts are shown beside the stored ones so you can judge each.
